전체 공지 / 결석 알림톡 발송

반을 선택하거나 검색한 뒤 학생을 불러오고, 원하는 학생만 체크해서 공지를 발송합니다.

수신 대상 발송 방식
공지 대상 0명

알림톡 발송내역

Firestore 발송기록과 SOLAPI 실제 전송 상태를 확인합니다. 접수 성공과 최종 전달 완료를 구분해 표시합니다.

출석부 확인 / 출결 발송

학생명단의 수강반을 기준으로 출석부와 태블릿이 함께 갱신됩니다.

수신 대상
발송 방식
알림톡은 승인된 템플릿 ID가 필요하고, 문자는 SOLAPI 발신번호 등록이 필요합니다.
강사 권한은 발송이 제한됩니다. 출석 확인과 일일평가 저장만 가능합니다.

수강생 수업 일일평가

학생의 일일평가 작성. 수업일 선택-> 반명 선택 또는 검색-> 현재 반 학생 불러오기-> 작성 완료후 평가저장

사용 가능 치환어: [학생명], [반명], [반이름], [출석여부], [수업일], [담당강사], [수업내용], [수업태도], [전달사항], [수업영상링크]
평가 수신 대상
발송 방식
일일평가 알림톡은 승인된 평가 템플릿이 필요합니다.

발성/기출 연습일지 체크

날짜별 발성훈련·기출문제 녹음 기록을 확인하고, 녹음파일과 분석결과를 확인하고 학생에게 남길 강사 코멘트를 작성합니다.

조회 전

강의실 사용체크

강의실별 사용 현황을 시간표 형태로 확인합니다.
표의 [사용] 버튼을 누르면 운영자료에 즉시 반영되어 다른 사용자 화면에도 표시됩니다.
사용 현황은 운영자료에 바로 저장되며 백업자료는 별도로 유지됩니다.

조회 전 초록: 사용중 기준 데이터: 운영 원본 저장 즉시 실시간 반영 관리자: 사용중 칸 클릭 후 배정/용도변경 가능
※ 관리자는 원하는 날짜·시간·강의실에 강사를 직접 배정하거나, 기존 사용칸을 해제/용도변경할 수 있습니다. 강사는 본인이 체크한 기록만 해제할 수 있습니다.
